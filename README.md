Designed to help admins easily manage WhatsApp groups.

---

📖 About

XHUNTERBOT is designed for WhatsApp group automation and moderation.
It supports multi-device login, runs on Node.js, and uses the Baileys library for WhatsApp Web API integration.

Lightweight, fast, customizable, and perfect for personal or public use.


---

🛠️ Installation

Requirements:

Node.js

Git


Steps:

git clone https://github.com/DigitalBreach/XHUNTERBOT-BOT.git
cd XHUNTERBOT-BOT
npm install
node index.js

Scan the QR / use Pair Code to connect your WhatsApp.
